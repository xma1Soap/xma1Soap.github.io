Slay the Spire 2

0.107.0 beta更新

2026-06-05·翻译 · 星薄荷
v0.107.0 上线！这一版主要是为测试分支并入主线做的收尾工作——少量数值调整，大量 Bug 修复和 UI 改进，还有新的故障机器人动画。
目录
  • 内容与平衡性
  • 体验优化
  • 用户界面与体验
  • 美术
  • 文本
  • Bug 修复
  • 性能
  • Mod 支持

内容与平衡性

敌人

  • 加强 鬼祟珊瑚群：在高进阶下，它获得力量的回合现在额外 +1 力量
  • 调整 永世沙漏：
    • 不再施加退潮减益效果
    • 现在在退潮动作（单次攻击）上获得格挡，而非在增强强度动作上获得格挡

药水与遗物

  • 加强 发条靴 遗物：伤害提升现在也对奥斯提的攻击生效

铁甲战士

  • 加强 势不可当 卡牌：伤害从 5(7) 提升至 6(8)

储君

  • 加强 王之凝视 卡牌：能量消耗从 3(2) 降低至 2(1)
  • 削弱 倒映 卡牌：格挡获取从 16(20) 降低至 15(20)

亡灵契约师

  • 加强 紧追不放 卡牌：召唤数从 2(3) 提升至 3(4)
  • 加强 巨镰 卡牌：伤害从 3(4) 提升至 4(5)

体验优化

  • 在地精佣兵战斗中，如果地精佣兵没有偷到任何金币但胖地精逃脱了，玩家现在能获得正常金币奖励的 50%，而非 0%

用户界面与体验

通用

  • 如果开局时发生错误，现在会弹出提示窗口而非黑屏
  • 为随机角色选项实现了偏好进阶设置

先古之民

  • 当瓦库告诉你曾经拜访过他的次数时，他说的数字现在是准确的了
  • 佩尔之肉 遗物现在会在能量计数器中直观地显示提高后的最大能量值
    • 例如，如果你在佩尔之肉触发前有 3 点最大能量，触发后你的能量计数器会显示 4/4 而非 4/3

敌人

  • 凋萎状态卡牌的预览升级等级现在与永世沙漏实际所处的升级等级一致

亡灵契约师

  • 牺牲 卡牌现在会预览即将获得的格挡值，以便在计算敏捷和脆弱等效果时更容易规划

美术

  • 为以下纪元添加了美术：毁灭、十二之数、巨人
  • 添加了故障机器人充能动画
  • 添加了新的灵魂枢纽视觉效果

文本

  • 更新了多种语言的翻译

Bug 修复

通用

  • 如果你关闭了 Steam 云存档，云文件不再覆盖本地文件
  • 携带藏宝图任务卡牌时，第二章的第一个房间不再会出现为 ? 房间而非战斗
  • 修复了卡牌能量消耗在随机化时偶尔显示错误数值的问题
  • 修复了在选择卡牌时取消选择后卡牌回到手牌错误位置的问题
  • 战斗结束后抽牌阶段不再触发抽牌
  • 繁茂章节现在会播放它的两首音乐曲目，而非总是播放同一首
  • 音乐在开局时不再重复播放两次

先古之民

  • 修复了玩家拥有瓦库的低语耳环遗物且自动打出虚空形态卡牌后，有时会在玩家下一回合继续自动打出卡牌的问题
  • 修复了诺奴佩普的钻石头冠遗物在地狱狂徒能力在回合开始时打出卡牌后重置计数的问题

敌人

  • 永世沙漏的凋萎状态卡牌不再在回合结束弃牌前短暂回到手牌中
  • 凋萎状态卡牌不再能被武装或生命汲取卡牌升级
  • 修复了击杀幽灵骑士后，本应为虚无的卡牌偶尔会变为非虚无的问题
  • 修复了生物和 Boss 的视觉效果偶尔无法显示的问题
  • 修复了飞蝇菌子的孢子效果在攻击被打断后持续存在的问题
  • 修复了化石追踪者的视觉效果在怪物图鉴中持续播放的问题
  • 修复了活雾的死亡语录中的遭遇名称
  • 如果你在地精佣兵偷到金币前击杀了他，即使胖地精逃脱了，奖励界面也不再显示"被抢了……"

药水与遗物

  • 修复了玩家在休息处孵化多尼斯异鸟蛋时，如果卡组中其余卡牌均已升级且拥有迷你帐篷遗物，新加入的异鸟扑击卡牌要到下一次休息处才能升级的问题
  • 修复了缩放仪遗物将玩家治疗至 50% 生命值以上后，红头骨遗物的力量加成仍会在打出攻击前生效的问题
  • 异蛇头骨遗物现在总是在不安油灯遗物之前触发
  • 修复了部分药水素材轮廓的视觉错误

事件

  • 扭曲锤子遗物不再能在遗物交换商事件中被交易
  • 修复了当附魔卡牌在你的手牌或抽牌堆中时打出重启卡牌后，完美契合附魔失效的问题
  • 修复了战史学家付袭事件在你拥有超过 2 张灯火钥匙时无法移除所有重复卡牌的问题

静默猎手

  • 修复了玩家拥有不休陀螺遗物时打出隐秘匕首卡牌并弃掉一张狡诈卡牌后，不休陀螺可能导致玩家在小刀加入手牌之前错误地抽牌的问题

亡灵契约师

  • 修复了玩家打出致死性卡牌且本回合首次攻击带有重放时，重放的攻击会在正确造成基础伤害值之前错误地显示致死性强化后的伤害数值的问题

多人模式

  • 修复了在多人模式中使用药水时因状态不同步而导致的崩溃
  • 修复了在特定事件中获得卡牌时偶尔显示错误卡牌的罕见问题
  • 夜魇卡牌的视觉效果不再对所有玩家播放

性能

  • 减少了本局中首次出现战斗效果时的卡顿现象

Mod 支持

  • 基础游戏不再删除已被移除或出错的 Mod 的进度
